## 📖 项目简介

OSSU（Open Source Society University）课程体系是一套**完全基于在线免费资源的计算机科学完整教育**,不止面向职业培训,更为想要系统、全面打牢计算学科基础概念的自学者而设计。课程按本科计算机科学专业的学位要求组织(不含通识课),精选自哈佛、普林斯顿、MIT 等顶级高校,由全球学习者社区互助支持。只要规划得当、每周投入约 20 小时,大约两年即可完成全部课程。

## ✨ 主要特性

- **完整的 CS 本科级课程体系**:从入门(Intro CS)、核心(Core CS)到进阶(Advanced CS)再到毕业项目(Final Project),路径清晰
- **顶级课程来源**:课程多来自 MIT、哈佛、斯坦福、普林斯顿等名校的公开课
- **严格的遴选标准**:课程必须开放注册、定期开课(最好可自学)、教学质量高,并符合 CS 2013 本科教学大纲
- **零学费起步**:几乎所有课程材料免费;Coursera 与 edX 均可申请助学金
- **时间可估算**:官方提供电子表格工具,输入起始日期与每周学习时长即可预估完成时间
- **社区支持**:Discord 社区、GitHub Issues 讨论区,全球学习者互助
- **进度可视**:Fork 仓库后用 ✅ 标记已完成课程,即成为你的看板
- **配套资源**:另有 extras 扩展课程与延伸阅读清单

## 🚀 快速开始

1. 访问 [原项目](https://github.com/ossu/computer-science) 或 [OSSU CS 网站](https://cs.ossu.dev) 查看最新课程列表;
2. Fork 原仓库到自己的 GitHub 账号,方便追踪学习进度;
3. 已有编程/数学基础者可直接从 Core CS 开始,零基础建议先修 Intro CS;
4. 核心课程(Core CS)建议按从上到下的顺序修读,数学课可与入门课并行;
5. 进阶课程(Advanced CS)为选修,按兴趣方向选一个主题方向修完全部相关课程;
6. 每完成一门课,在 Fork 的仓库中对应课程旁打 ✅ 作为看板;
7. 加入官方 Discord 与全球学习者交流,遇到课程问题可在 GitHub Issues 提出;
8. 完成核心与进阶课程后,选择毕业项目(Final Project)方向,综合运用所学知识。

```bash
# Fork 并克隆原仓库以追踪你的学习进度(课程内容均在原仓库)
git clone https://github.com/<你的用户名>/computer-science.git
```
